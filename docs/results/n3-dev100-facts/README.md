## 配对比较（基准 B2，同一批 100 题）

`uv run python scripts/paired_compare.py runs/eval/dev100-n3 --base B2 --others ...`

| 方法 | B2 对、它错 | B2 错、它对 | 净提升 | 符号检验 p |
|---|---|---|---|---|
| B2F | 3 | 18 | +15 | 0.001 |
| B2F-keys（只用事实增强键） | 2 | 15 | +13 | 0.002 |
| B2F-current（只给当前事实） | 4 | 19 | +15 | 0.003 |
| B2F-plain（不标有效期） | 3 | 18 | +15 | 0.001 |
| B2F-noprofile（不给核心记忆） | 3 | 17 | +14 | 0.003 |
| B1 全上下文 | 8 | 15 | +7 | 0.210 |
| ORACLE | 2 | 20 | +18 | <0.001 |

以 B2F 为基准时，四个消融的差异都不显著（p ≥ 0.77），ORACLE 也不显著（+8 / −5，p = 0.58）。

## 对账规则修订前后（D-019）

首轮运行（`runs/eval/dev100-n3-rules`）里，登记过的单值谓词按规则直接取代；抽样核对后改为一律由 LLM 确认，并修正了事件时间与说出时间混比的错误。抽取结果相同（命中缓存），只重做了对账。

| 指标 | 修订前（规则取代） | 修订后（LLM 确认） |
|---|---|---|
| B2F 准确率 | 81% | 80% |
| 知识更新题 | 13 / 15 | 15 / 15 |
| 取代次数（100 份历史） | 451 | 159 |
| 由 LLM 裁决的对账 | 11.7% | 13.2% |
| 抽样核对的取代精确率 | 规则约 10%（31 次中 3 次），LLM 约 64%（28 次中 18 次） | — |

总体准确率差 1 题，在噪声范围内；但修订前的 2 道知识更新错题都是错误的"已失效"标签造成的，修订后消失。

## 跨数据集检查：LoCoMo

LoCoMo 前 3 段对话（385 题，不含对抗题），没有在 LoCoMo 上调过任何参数：B2 71.2% → B2F 77.7%（配对 +42 / −17，p = 0.002），ORACLE 87.5%；多跳 42% → 61%，时间题持平。报告见 [../n3-locomo-3conv/report.md](../n3-locomo-3conv/report.md)。
